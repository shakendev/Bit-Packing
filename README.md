# Bit Packing Concept App

A project concept that reflects the essence of the mechanism for packing Boolean values ​​into bytes/words, etc., specifically the OptionSet protocol in Swift.

This concept can be used to implement packing of non-standard bit sizes, such as structures consisting of UInt8 and 1-8 Boolean values, etc.

This mechanism is applicable in the development of real-time applications, where it is important to pack parameters as close to each other as possible, bypassing memory defragmentation, increasing the speed of access to the property, as well as the safety of atomic operations.
